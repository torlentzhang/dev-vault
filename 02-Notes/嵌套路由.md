# 嵌套路由

## 一句话定义
用 `children` 数组表达"父组件里还嵌着子路由视图"的结构，父组件模板里放 `<router-view>` 承接子组件。

## 要点
- 配置：`{ path: '/user/:id', component: User, children: [ { path: 'profile', component: UserProfile }, { path: 'posts', component: UserPosts } ] }`。
- 渲染：父组件 `User.vue` 模板里必须放一个 `<router-view />`，子组件才渲染得进去；顶层 `<router-view>` 渲染顶层路由。
- 子路由 `path` 是**相对路径**（不带 `/`），拼到父路径后；**以 `/` 开头的子路径视为根路径**（可借嵌套结构但不嵌套 URL）。
- **空 path 默认子路由**：`{ path: '', component: UserHome }`——访问 `/user/:id` 时不带子段时渲染它。
- 4.1+ 可省略父级 `component`，只借父子关系做分组（如共用路径前缀、统一 `beforeEnter` / `meta`），顶级 `<router-view>` 跳过父级直接用子组件。
- 常与 [[命名路由]] 配合（通常只给子路由命名），也常配合 [[路由懒加载]]。

## 我的理解 / 类比
像带抽屉的文件柜：柜子（父组件）本身占一个位置 `/user/:id`；拉开某个抽屉（子路由 `profile` / `posts`）才看到里面的内容，抽屉嵌在柜子里。

## 关联
