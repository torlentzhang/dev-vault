# 命名路由

## 一句话定义
给路由记录加 `name` 字段，之后用名字而非路径字符串来跳转 / 生成链接，避免硬编码 URL。

## 要点
- 定义：`{ path: '/user/:username', name: 'profile', component: User }`。**所有路由的 `name` 必须唯一**，重名只保留最后一条。
- 使用：`<router-link :to="{ name: 'profile', params: { username: 'erina' } }">` 或 `router.push({ name: 'profile', params: { username: 'erina' } })`。
- 好处：① 没有硬编码 URL；② `params` 自动编码 / 解码（含 `/`、空格等）；③ 防止 URL 打字错误；④ 绕过路径排序（匹配相同路径但排序较低的路由）。
- ⚠️ 传 `params` 必须用 `name`（见 [[路由params与query的区别]]、[[编程式导航router.push]]）；用 `path` 时 `params` 被忽略。
- 嵌套路由通常只给子路由命名（见 [[嵌套路由]]）。

## 我的理解 / 类比
像给同事起绰号：叫"老张"比记工号（路径）省事，老张换工位（路径改了）你照样能找到他，不用改通讯录里每一处。
