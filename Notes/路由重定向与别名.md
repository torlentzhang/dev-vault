# 路由重定向与别名

## 一句话定义
`redirect` 让访问 A 时 URL 换成 B 并渲染 B；`alias` 让访问 A 时 URL 不变却渲染 B——一个改地址、一个改映射。

## 要点
- **redirect**：`{ path: '/home', redirect: '/' }`；目标可为字符串路径、`{ name: 'homepage' }`、或函数 `to => ({ path: '/search', query: { q: to.params.searchText } })`。
  - ⚠️ **守卫只应用在重定向的目标上**，不在源路由上；所以给 `/home` 加 `beforeEnter` 无效。
  - 可省略 `component`（从不被直接访问）；但带 `children` + `redirect` 时必须保留 `component`。
  - 支持相对重定向（函数里 `to.path.replace(...)`）。
- **alias**：`{ path: '/', component: Homepage, alias: '/home' }`——访问 `/home` 时 URL 仍是 `/home`，但渲染的是 `/` 的组件。可给数组多个别名 `alias: ['/people', 'list']`。
  - 有参数时要保证绝对别名也含参数：`alias: ['/:id', '']`。
  - 注意 SEO：用别名要定义规范链接（canonical）。
- 区别记忆：**redirect = 换门牌；alias = 一个房子多个门牌但地址牌不变**。

## 我的理解 / 类比
redirect 像"你按旧门牌来找，物业直接把你领到新门牌"；alias 像"这房子挂了两个门牌号，你念哪个都进同一扇门，门口写的还是你念的那个号"。
