# 成因式人设

## 一句话定义
写人设时描述**这个表现是怎么来的**——从什么起点开始、经过什么反应、怎么固化成了现在这个样子，而不是罗列表面特征。成因能推导出多种外在行为，特征只能被逐个复述。

## 用于解决什么问题
按「喜欢喝酒、话不多、讨厌被同情」这样列出的人设，模型只能用最直白的方式把每条演一遍。几轮之后开始循环，角色从「有性格」退化成「在背设定」。

## 要点

### 从指定结果，到给出成因
| 写法  | 例子                                     | 类别       |
| --- | -------------------------------------- | -------- |
| 特征  | 他喜欢喝酒                                  | 直接指定结果   |
| 规则  | 别人提家里事他就讲路况                            | 条件指定结果   |
| 需求  | 他需要有件事在做，才说得上话                         | 他在解决什么   |
| 成因  | 他下岗后一直觉得自己不算数，只有后座有人、由他决定往哪走，他才觉得自己在做事 | 这个表现怎么来的 |

前两种都是对结果的一次性指定，区别只在挂不挂条件。指定得再细，也只产出它自己。

后两种能长出多种行为，但深浅不同。需求回答「他在解决什么」，已经够用：说清他要什么，模型在各个场景里会自动找办法。成因再往前推一步，回答「这个表现是怎么来的」，它就落到了一个具体的人身上，不会退化成一句谁都能套的通用动机。

需求是成因里的一段，不是与它并列的另一件事：需求是他当时的应对动机，起点和固化在它两头。

「加条件」不会让指定变成成因。这是最容易误判的地方：把特征改写成「当 X 就做 Y」，看起来像流程，实际仍然是一次性指定。

### 一条成因长什么样
不是一句解释，是一条链：

```text
起点   嘴唇厚
反应   被人笑过，觉得难看，自卑
应对   抿嘴，想让嘴唇显得薄一点
固化   做了十几年，成了下意识的动作
```

缺了「固化」，它只是「他在掩盖嘴唇厚」；有了固化，它才是特征——他本人已经不记得为什么了。

同一条结构也套得住行为模式：

```text
起点   下岗，找不到活
反应   觉得自己不算数
应对   开出租，后座有人、由他决定往哪走
固化   话多起来，一直开到现在
```

一个是微动作，一个是行为模式，差得很远，但生成方式是同一种：一个起点，一次应对，然后时间把它变成了习惯。

### 判据：换掉这个反应，设定还成立吗
把设定里写的那个反应，换成一个同样合理的，看设定受不受影响。

- 「别人提家里事他就讲路况」：设定锁死的就是「讲路况」。换成「骂天气」，它就不再是这条设定 → **规则**，一种反应对应一条设定
- 「他下岗后觉得自己不算数，需要被人需要」：换成抢着帮人搬行李、反复解释路线、被质疑就急，设定都成立，只是换了个表现 → **成因**，一条设定对应多种反应

成因允许多种落地方式，规则只允许一种。

「多种」指的是多种做法都成立，不是一句话有多种解读。前者是好，后者是歧义。

但这个判据只能分开「规则」和「能生长的表述」，分不开「需求」和「成因」。「他只有握着方向盘时才说得上话」能换成讲发动机、讲乘客，它过得了这一关，却仍然只是需求——说的还是他怎么做事。再问一句「这个表现是怎么来的」，才落到成因。

### 具体在因上，抽象在果上
```text
规则：抽象触发 + 具体反应
成因：具体来源 + 抽象倾向
```

规则把两者搞反了：因写得干瘪，果写得死板。反应被钉死，模型没有余量。

### 三个步骤
1. 把清单分两类：可推导的（性格、习惯）与不可推导的（口音、年代、职业）。后者推不出来，直接写，但压到最短。
2. 对可推导的，问「这个表现是怎么来的」：起点是什么，他当时想解决什么（需求），后来怎么固化。三段答全，才是一条成因；只答中段，写出来的还是需求。
3. 给这个需求配一个**不太有效的解法**，并且让他认为有用。行为和台词之间的裂缝由此产生。

能替换的才叫需求，不能替换的只是习惯。写需求，模型在场景变化时会自己找替代方案。

### 可以安全保留的两种写法
- **推不出来的事实**：必须直接写（「话不多」「五十岁」「嘴唇厚」）。它们不只是背景，常常正是成因链的起点——删掉它，整条链就没有根。
- **留白**：留一处他自己也不解释的点。放在口味、对某类人的态度这类地方；不要放在核心动机和说话方式上——那里留空会被通用刻板印象填满。

### 常见混淆
- 成因不等于更长的特征。`他父亲开酒吧 / 十九岁开始喝 / 三十岁戒了` 写成故事口吻，仍然是清单。
- 「生活的重担」不构成成因。没有具体内容的因等于没写，只能渲染情绪，推不出行为。
- 形容词、特征、规则属于同一条轴：都是在直接指定性格。「痴狂」指定得极窄，只剩两三种演法；「温柔」指定得极宽，宽到谁都能算，最后长成通用「好人」。堆同义词（温和、温良）不会扩大范围，只是把同一句话说三遍。两个方向都写不出具体的人，所以形容词只适合当标签，真要立住还得回到成因。

## 我的理解 / 类比
写法是**说明书**，成因是**生平**。说明书列了什么就只能做什么，生平能推出没写进去的事。
