# 前端路由

## 一句话定义
在单页应用（SPA）中，监听 URL 变化、按路由表匹配出对应组件、并替换渲染区内容，而**不刷新整页**的机制。

## 要点
- 多页应用（MPA）：每次跳转都向服务器请求一整份新 HTML，整页刷新。
- 单页应用（SPA）：页面只加载一次，之后"切换视图"靠 JS 完成——URL 变了，但**不重新请求整页**，只把对应组件挂到 `<router-view>` 占位处。
- 路由系统的核心环节：`URL 变化 → 监听变化 → 匹配路由表 → 渲染对应组件`；当前路由对象是响应式的（`useRoute()` 拿到的 `route` 会变），所以模板自动刷新。
- Vue 生态的官方实现是 **Vue Router**（Vue 3 配 Vue Router 4）。
- 两种 URL 风格：Hash 模式（`#/user/1`）和 History 模式（`/user/1`），见 [[hash模式与history模式]]。

## 我的理解 / 类比
像电视机换台：电视机（页面容器 `#app`）一直都在，换台只是把"节目"（组件）换掉，不会把电视机拆了重装。URL 是频道号，路由表是"频道号 → 节目"的对照表。
