# 路由懒加载

## 一句话定义
把 `component` 写成"返回 Promise 的动态 `import()`"，让对应组件只在第一次进入该路由时才下载，做代码分割、减小首屏体积。

## 用于解决什么问题
所有路由组件打进一个包时，任意一页改一行都会让整包 hash 变化，用户发版后要重下全部代码；按路由拆开后只有对应 chunk 失效，其余仍走缓存。

## 要点
- 写法：`{ path: '/users/:id', component: () => import('./views/UserDetails.vue') }`；Vue Router 只在首次进入时才调用这个函数并缓存结果。
- 动机：打包后单包过大会拖慢首屏；按路由切分后，首屏只加载当前页所需代码。
- 分组（同 chunk）：
  - Webpack：`import(/* webpackChunkName: "group-user" */ './UserDetails.vue')`
  - Vite：在 `vite.config.ts` 的 `build.rollupOptions.output.manualChunks` 里按目录 / 模块手动分组。
- ⚠️ **不要把路由组件写成异步组件**（`defineAsyncComponent`）——路由组件本身就是动态 import，异步组件仍可在路由组件内部使用。
- 一般建议对所有路由都使用动态 import。

## 我的理解 / 类比
像买书不一次性搬空仓库，而是"读者要看哪本，仓库才发哪本"——首屏只发你当前这页的书，别的等你要看时再发。
