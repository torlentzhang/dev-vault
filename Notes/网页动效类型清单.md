# 网页动效类型清单

## 一句话定义
网页动效是页面里由**指针、滚动或时间**驱动的视觉变化。常见的「十六种」清单里，十四个是看得见的**手法**，两个（缓动、弹性）是控制所有动效的**参数**——它们不在同一维度。

## 用于解决什么问题
两个问题。一是**辨认**：光效、位移、文字逐字出现这类效果彼此相近，名字也混着用，先弄清它们各自在动什么，才谈得上选。二是**落地**：动效要能被准确描述，才知道该写 `transition`、`animation` 还是监听指针与滚动事件——模糊的「做得高级一点」对应不到任何实现。

## 要点

### 十六种的两个层次
- **手法（14）**：边缘流光、聚光、3D 倾斜、滚动叙事、乱码解码、视差滚动、磁吸、打字机、跑马灯、流光、数字滚动、滚动出现、错峰、悬停上浮
- **参数（2）**：缓动、弹性

手法与参数不在同一维度：前者决定「动什么」，后者决定「怎么动」。十六者并非平行可选项，实际是**先定手法，再用参数调手感**。

### 按驱动方式归组

| 驱动 | 动效 | 机制 | 典型场景 |
| --- | --- | --- | --- |
| 指针 | 聚光 | 一团光跟着指针走，同时照亮卡片与边框 | 卡片聚焦区 |
| 指针 | 3D 倾斜 | 按指针方位做透视倾斜，像拿在手里转着看 | 产品卡、会员卡 |
| 指针 | 磁吸 | 指针接近时朝指针小幅位移 | 首页唯一的核心大按钮 |
| 指针 | 悬停上浮 | 微微浮起 + 阴影变化 | 提示「这块可以点」 |
| 滚动 | 滚动出现 | 进入视口才淡入 / 滑入 | 长页面的阅读节奏 |
| 滚动 | 视差滚动 | 背景比前景移动慢，造出纵深 | 官网首页 |
| 滚动 | 滚动叙事 | 画面固定、内部内容随滚动分段变化，像翻动画书 | 苹果产品页 |
| 时间 | 边缘流光 | 一道光沿边框一圈圈转 | 推荐套餐、新功能卡片（常见叫法 `border beam`） |
| 时间 | 流光 | 一道光从表面扫过 | 骨架屏加载态、按钮引诱 |
| 时间 | 跑马灯 | 内容从右往左无限循环 | logo 墙、评价区 |
| 时间 | 打字机 | 逐字打出 + 末尾闪烁光标 | 首页大标题、AI 回复 |
| 时间 | 数字滚动 | 从 0 快速滚到目标值 | 「已服务 10000 位用户」 |
| 时间 | 乱码解码 | 先乱跳字符，再逐个定格成正确的字 | 标题、数字展示 |
| 时间 | 错峰 | 一组元素按序出现，间隔零点零几秒（例 0.05s） | 列表卡片墙的层次感 |
| 参数 | 缓动 | 速度随时间怎么变 | 所有动效 |
| 参数 | 弹性 | 冲过终点再回弹 | 点赞、弹窗 |

### 运动参数的两条要点
- **缓动**：全程匀速像机器在跑；**先快后慢（`ease-out`）最自然**。进场用减速，离场要比进场更快更轻——同时把所有动效设成同一速度会让画面显得僵硬。它只改速度曲线，**不越过终点**。
- **弹性**：刻意越过终点再回来，果冻感。适合点赞、弹窗这类趣味场景，别滥用在正文。弹窗宜从小尺寸放大回原尺寸，而不是从 0 放大。

### 时长与性能
- **时长参考**：Material Design 3 的 duration token 从 short1 50ms 到 long4 600ms（short2 100ms、short3 150ms、short4 200ms、medium1 250ms、medium2 300ms）。小控件用 short 级，大面积的进场用 long 级；0.1–0.3s 覆盖了绝大多数交互反馈。
- **性能**：只动 `transform` 与 `opacity`。二者在自身图层中渲染，更新由合成阶段处理，**不触发重绘**；改动几何或位置（`left`、`margin`、`font-size` 等）则会依次引发样式重算、布局与重绘，更容易掉帧。60fps 下每帧只有约 16.7ms 完成这一整条流水线。
- **同时跑多个动效**：统一成同一速度会让画面显得僵硬，按重要性区分节奏。

### 无障碍适配
放大、平移大元素这类动效会诱发前庭不适，需要提供关闭手段：

```css
@media (prefers-reduced-motion: reduce) {
  /* 关掉或替换动效 */
}
```

`prefers-reduced-motion: reduce` 对应系统里「减弱动态效果」类设置，Baseline 自 2020 年 1 月起各浏览器广泛可用。

### 名字是可执行接口
动效要能被准确要求出来，模糊描述（「做得高级一点」）无法落地，规范名称（如 `border beam`、`marquee`）才能对应到具体实现。命名本身不改变动效，它决定的是沟通与检索的成本。

### 最容易混的几对
- **边缘流光 vs 流光**：前者光被约束在**边框轮廓**上绕行，后者是**整个表面**被扫过。
- **聚光 vs 流光**：聚光是**跟随指针的局部光斑**（位置被指针牵着走），流光是一道**周期性扫过的光**（位置自己跑）。
- **滚动出现 vs 滚动叙事**：前者只是**入场一次**，后者是**滚动位置持续驱动内容变化**。
- **滚动出现 vs 视差滚动**：前者是元素自身的出场动画，后者是多层之间的相对速度差。
- **悬停上浮 vs 3D 倾斜**：都靠 hover，前者整体位移 + 阴影（表达「可以点」），后者视角倾斜（表达「这是个实物」）。
- **磁吸 vs 悬停上浮**：磁吸的位移方向**跟着指针**，上浮是**固定向上**。
- **弹性 vs 缓动**：缓动只调速度曲线，弹性是**故意越界**——CSS 里靠 `cubic-bezier` 或 `linear()` 造出回弹。
- **跑马灯是个反例**：它要**匀速**，与「先快后慢更自然」相反，因为它是持续循环而非一次性过渡。

### 跑马灯与 `<marquee>`
`<marquee>` 曾是实现跑马灯的标签，已被废弃且强烈不建议使用。横向循环滚动应当用 CSS 动画，并按 `prefers-reduced-motion` 关停。`marquee` 在 CSS 里也是 `overflow` 的取值之一，与这个标签无依赖关系。

## 我的理解 / 类比
十四个手法像**修辞**：比喻、排比、反问，各是各的招，用不用看场合。缓动与弹性却是**语速**——修辞可以少用几句，语速不对，整段话听着就别扭。
