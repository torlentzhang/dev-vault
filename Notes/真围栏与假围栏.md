# 真围栏与假围栏

## 一句话定义
约束应该写成**关于角色的陈述句**，削减他不可能做的事；而不是**规定输出长什么样**。后者是伪装成约束的脚本。

## 用于解决什么问题
人设加约束是为了防止走偏，但越加越僵、越加越像在背指令。原因是把「描述这个人」写成了「命令模型」。

## 要点

### 两种围栏
|      | 假围栏（规定输出）        | 真围栏（排除可能）      |
| ---- | ---------------- | -------------- |
| 写法   | 她说话简短、语气冷淡、不主动关心 | 她不会让任何人看出她在意什么 |
| 约束的是 | 输出长什么样           | 什么不能发生         |
| 加到十条 | 十条都要演，立刻机械       | 人更窄，但仍然自由      |

假围栏本质是脚本，只是伪装成了约束，所以加得越多越僵。真围栏不规定说什么，只排除一类可能，模型为了满足它每轮都得现场想办法。

### 怎么验一条围栏
删掉它，或者把它换成另一种同样说得通的说法，看他会不会做出不像他的事：会，是围栏；不会，是装饰。测法见 [[替换测试]]。

### 写成陈述句，不写成禁令
禁令走指令跟随，要求输出时把概念取反；关于角色的事实走推理，与「成因」同一条通道。后者不会激活被否定的概念。展开见 [[词汇层否定与风格层否定]]。

### 负面清单比正面清单更能生长
「他绝对不会在人面前哭」比「他很能忍」有用：后者是标签，只能被表演；前者排除掉一大半可能，模型得自己找剩下的路。

### 与成因的分工
[[成因式人设|成因]]往里放东西，给方向；围栏往外切东西，给值域。

两者都不指定具体反应，但缺一个都会出问题：只有因会飘，只有围栏会僵。

### 假围栏不是特征清单
[[成因式人设]]里的特征和规则，是对**内容**的一次性指定（喜欢喝酒、谁提家里事就讲路况）；假围栏指定的是**表现样式**（一直简短、一直冷淡）。前者限制说什么，后者限制长什么样，失败方式也不同：清单被逐条复述，样式被逐轮表演。两者都不能生长，所以常被读成同一件事。

## 我的理解 / 类比
成因是**给演员的背景**，围栏是**舞台边界**。没有背景只能演类型，没有边界会走下台。
