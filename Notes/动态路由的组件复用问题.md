# 动态路由的组件复用问题

## 一句话定义
从 `/user/1` 切到 `/user/2` 时，同一个组件实例被**复用**而非销毁重建，导致 `onMounted` 等生命周期不重跑、基于旧参数的数据不刷新。

## 要点
- 根因：两个路由渲染同一个组件，Vue Router 选择复用实例而非销毁重建（更高效）。副作用是**生命周期钩子不会被再次调用**。
- 表现：`onMounted` 里拉的数据不会更新、`ref` 初始值不重置，但 `route.params.id` 确实变成了新值。
- 解法 A——`watch` 监听参数：
  ```ts
  import { watch } from 'vue'
  import { useRoute } from 'vue-router'
  const route = useRoute()
  watch(() => route.params.id, (newId) => { fetchUser(newId) })
  ```
- 解法 B——组合式守卫 `onBeforeRouteUpdate`（更语义化，还能取消导航）：
  ```ts
  import { onBeforeRouteUpdate } from 'vue-router'
  onBeforeRouteUpdate(async (to) => {
    userData.value = await fetchUser(to.params.id)
  })
  ```
- 记忆口诀：**换页不换组件，mounted 不重来；要响应变化就 `watch` 或 `onBeforeRouteUpdate`**。

## 我的理解 / 类比
像同一间教室换了上课的学生（参数变了），但教室（组件实例）没拆了重建，所以"开学典礼"（onMounted）不会重播——得靠"点名"（watch）或"班主任换班通知"（beforeRouteUpdate）来重新准备。
