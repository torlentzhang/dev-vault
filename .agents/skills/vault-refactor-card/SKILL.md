# 改名/移动原子卡片（vault-refactor-card）

适用：重命名或移动 02-Notes 下的卡片，保证图谱不断链。

## 前置
- 改名/移动属 L2：按 AGENTS.md「安全分级」，先向用户说明旧名→新名及将影响的文件路径，获同意后再执行。

## 步骤
1. 全库搜旧名的所有引用。Obsidian 有显示别名语法，必须用正则同时命中两种形态：
   `\[\[旧名(\|[^\]]*)?\]\]`（覆盖 `[[旧名]]` 与 `[[旧名|显示文字]]`，且不会误伤同前缀卡名）。覆盖三处：
   - 各 MOC（00-Index）的列表项 `- [[旧名]]`
   - 其他卡片 `## 关联` 区里的回链
   - 卡片正文中的内联引用 `[[旧名]]`
   另用裸词 `旧名` 再搜一遍，找 frontmatter aliases 等非链接出现处。
2. 将全部 `[[旧名]]` 替换为 `[[新名]]`；`[[旧名|显示文字]]` 替换为 `[[新名|显示文字]]`（显示文字保留）。文件名同步改。
3. 检查 frontmatter 的 `aliases`：若含旧名或与之冲突/失效，一并更新。
4. 改完按同一正则再全库搜一次，须为 0 命中；非 0 说明还有遗漏，继续补替换。
5. 同步 README：纯改名只需把 README 中所有旧卡名替换为新名（「二、目录编排」02-Notes 清单 + 文末 MOC 归属表），计数不变；
   若移动目录（如 02-Notes→03-Projects），同步调整 MOC 归属与 README 计数（计数方法见 AGENTS.md）。

## 最小示例
把 `Sass的use与forward` 改名为 `Sass的use与forward规则`：
1. 正则 `\[\[Sass的use与forward(\|[^\]]*)?\]\]` 全库搜 → 命中 MOC-前端基础 的列表项 + 若干卡片的 `## 关联` 回链
2. 全部替换为 `[[Sass的use与forward规则]]`，文件名同步改
3. 复搜同一正则须 0 命中；README 两处清单中的旧卡名替换为新名，计数不变

## 注意
- 安全确认流程统一遵循 AGENTS.md「安全分级」。
